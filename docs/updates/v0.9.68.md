# sobe v0.9.68-beta

Esta version anade una herramienta para exportar tu mapa a video (.mp4), afina el cursor Auto para que se mueva mas como un humano, y trae varias mejoras de calidad de vida en el editor.

## Exportar video

Ahora puedes renderizar un trozo de tu mapa a un .mp4 desde el editor, listo para compartir. En el menu Export, elige "Export video...".

- Marca el inicio y el fin del clip con los botones Set in / Set out; la duracion del rango se muestra en vivo.
- Presets de calidad y de tamano. El preset de Discord ajusta el bitrate para que el video siempre entre bajo el limite de subida gratuito (10 MB), con una estimacion del peso final que se actualiza sobre la marcha.
- Se renderiza una vista de gameplay limpia (sin la interfaz del editor): fondo, objetos y cursor Auto. El cursor se puede activar o desactivar.
- Hitsounds incluidos: se mezclan con la cancion en su tiempo exacto, usando los samples del mapa o de tu skin activa.
- Mods de render: HR, EZ, HD, DT y NC. HR y EZ no se combinan entre si, ni DT con NC. DoubleTime y Nightcore aceleran el video x1.5 con el audio acelerado (Nightcore ademas sube el tono).
- Carpeta de destino configurable con el boton Browse, que se recuerda entre sesiones.

Nota: la exportacion usa el editor en primer plano mientras dura, asi que hay que esperar a que termine (el mp4 se abre al acabar). De momento requiere tener ffmpeg instalado en el sistema.

## Cursor Auto mas humano

- Tras una pausa, el cursor ya no deriva lento hacia la siguiente nota: se queda quieto y hace el movimiento tarde, llegando justo a tiempo, como un jugador que reacciona al circulo.
- En streams densos, el enderezado ahora promedia sobre una ventana de varias notas, trazando una linea suave a traves de toda la tirada en vez de cancelar el zig-zag nota a nota.
- En sliders, el cursor serpentea un poco a cada lado del trazado (mas organico, menos robotico) y, al acercarse al final, empieza a derivar hacia el siguiente objeto (camino de menor esfuerzo) sin llegar a soltar ningun tick.

## Calidad de vida en el editor

- Mueve la seleccion pixel a pixel con las flechas del teclado.
- Salta entre bookmarks con Ctrl + flecha izquierda / derecha.
- Arrastra una imagen a la ventana para ponerla como fondo del mapa (se guarda al grabar).
- Genera automaticamente los colores de combo a partir del fondo.
- Overlay de angulos entre objetos.
